# Color-by-Code Gem — ตัวอย่างการสั่งงาน

เอกสารนี้รวบรวมตัวอย่างคำสั่งสำหรับใช้งาน Gem สร้างใบงาน Color by Code โดยเน้นการสั่งงานแบบง่ายสำหรับครู

## ค่าเริ่มต้นสำคัญ

หากผู้ใช้ไม่ระบุ ให้ถือว่า:

- ขนาดกระดาษ: A4
- แนวกระดาษ: แนวตั้ง
- ภาษา: ไทยเป็นหลัก
- รูปแบบโจทย์คณิตศาสตร์ในช่อง: แนวนอน
- ภาพหลัก: ขาว-ดำ เส้นชัด เหมาะสำหรับระบายสี
- ตารางรหัสสี: แสดงตัวอย่างสีจริงได้

## ตัวอย่าง 1 — คณิตศาสตร์ ป.3 การคูณ

```text
จำนวนสี: 6 สี
ธีม: โลกป่าดงดิบ
ขนาดกระดาษ: A4
แนวกระดาษ: แนวตั้ง
เฉลย: ไม่ต้องมี
รูปแบบโจทย์: แนวนอน
ตัวใบงาน: ขาว-ดำ
แสดงตัวอย่างสีจริงเฉพาะในตารางรหัสสีด้านล่าง
```

## หมายเหตุการใช้งาน

- ผู้ใช้ไม่จำเป็นต้องระบุพารามิเตอร์ทุกตัว
- หากไม่ระบุขนาดและแนวกระดาษ ให้ใช้ A4 แนวตั้ง
- หากไม่ระบุรูปแบบโจทย์คณิตศาสตร์ ให้ใช้แนวนอน
- หากจำนวนข้อเยอะเกินพื้นที่ ให้ Gem แบ่งหลายหน้าอัตโนมัติ
- หัวข้อที่มีคำตอบปลายเปิดควรถูกแปลงเป็นคำถามสั้นที่มีคำตอบชัดเจนก่อนใช้กับ Color by Code
