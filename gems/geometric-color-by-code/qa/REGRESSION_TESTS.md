# Geometric Color-by-Code — Regression Tests

Version: 1.8.1

## Core / mapping regressions
R1 FAIL if requested geometry is only decorative overlay.
R2 FAIL if density creates uncolorable cells.
R3 FAIL if one normalized answer maps to multiple colors.
R4 FAIL if distribution is discovered only after visual generation.
R5 FAIL if a legend entry has no mapped usage by default.
R6 FAIL if any answer/code is outside the active legend.
R7 FAIL if any region reaches render without a color ID.
R8 FAIL if arbitrary questions are generated first and colors are fitted afterward.
R9 FAIL if `COLOR_USAGE_PLAN` is not frozen before generated questions.
R10 FAIL if color usage counts do not sum to `QUESTION_COUNT`.
R11 FAIL if target answer/code differs from verified normalized answer after validation.
R12 FAIL if exact division has remainder or violates digit constraints.
R13 FAIL if changing color count only recolors legend without rebuilding domain/distribution.
R14 FAIL if fixed user questions render before 100% legend coverage is proven.

## Deterministic content-render regressions
R15 FAIL if image model is allowed to invent/rewrite final academic questions after verification.
R16 FAIL if final question numbers are generated by image model instead of deterministic source data.
R17 FAIL if final legend answer/code values are generated by image model.
R18 FAIL if `rendered_question_count != QUESTION_COUNT`.
R19 FAIL if any rendered question ID is duplicated unexpectedly.
R20 FAIL if any expected question ID is missing.
R21 FAIL if rendered question numbering is non-sequential when sequential numbering is required.
R22 FAIL if rendered prompt text differs from `VERIFIED_CONTENT_BLUEPRINT`.
R23 FAIL if rendered legend domain differs from `ACTIVE_LEGEND_DOMAIN`.
R24 FAIL if rendered color label/swatch differs from verified mapping/palette.
R25 FAIL if pre-render blueprint passes but post-render parity is skipped.
R26 FAIL if an image-model-only full-page academic-text render is called Gem-conformant or production-final.
R27 FAIL if OCR is used as the primary correctness mechanism even though deterministic renderer object metadata exists.
R28 FAIL if a beautiful high-density page is accepted despite missing/duplicated/changed questions.

## Geometry / line regressions
R29 FAIL if shared edges are doubled.
R30 FAIL if intended cells are open.
R31 FAIL if fuzzy/broken/hairline rendering is accepted as production-final.
R32 FAIL if final raster boundaries are independent of deterministic/vector master.
R33 FAIL if final Thai text uses uncontrolled font fallback.
R34 FAIL if text collides with borders.
R35 FAIL if line-quality failure is repeatedly regenerated without root-cause change.

## Natural Harmony regressions
R36 FAIL if natural proportion sacrifices readability/margins/legend.
R37 FAIL if approximate natural rhythm is described as exact without validation.
R38 FAIL if phyllotaxis creates cells below minimum colorable size.
R39 FAIL if Natural Harmony changes question count, IDs, answers, codes or colors.
R40 FAIL if unrelated themes mechanically reuse the same radial composition.

## Student / Answer-Key regressions
R41 FAIL if Student worksheet is solution-filled by default.
R42 FAIL if Student and Answer Key use separate geometry masters.
R43 FAIL if region/question/text identity differs between Student and Answer Key.
R44 FAIL if Answer Key colors are chosen by image-model interpretation.
R45 FAIL if even one Answer-Key region fill differs from verified mapping.
R46 FAIL if `ANSWER_KEY = NO` disables hidden correctness/mapping QA.
R47 FAIL if Student and Answer Key are placed on the same student-facing page by default.

## PASS principle
A regression passes only when visible academic content, answer-first generation, mapping, legend parity, question-ID integrity, readability, colorability, deterministic geometry, line quality and print usability all remain intact.
