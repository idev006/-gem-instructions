## แบบสั้นที่สุด

```text
สร้างใบงาน Color by Code ป.3 คณิต บวกเลข 1 หลัก 30 ข้อ 6 สี ธีมสวนดอกไม้ ใช้สามเหลี่ยมแบบ mosaic A4 แนวตั้ง
```

## เน้นหลักการ shape-first

```text
สร้างใบงาน Color by Code ธีมสวนดอกไม้ ใช้รูปสามเหลี่ยมเป็นองค์ประกอบหลักในการสร้างภาพทั้งหน้า ให้ดอกไม้ ใบไม้ และองค์ประกอบสวนเกิดจากการจัดกลุ่มสามเหลี่ยมเหมือนการปูกระเบื้อง mosaic ไม่ใช่วาดภาพปกติแล้วตีเส้นสามเหลี่ยมทับ
```
