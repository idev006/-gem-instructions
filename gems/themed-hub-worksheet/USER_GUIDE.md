# Themed Hub Worksheet — คู่มือการใช้งาน

Version: 1.1.0
Status: User Guide

## Gem นี้ใช้ทำอะไร

Gem นี้ช่วยสร้าง **prompt สำหรับออกแบบใบงานแบบมีหัวข้อหลักอยู่ตรงกลาง และมีช่องกิจกรรม/คำตอบกระจายรอบ ๆ** โดยสามารถเปลี่ยนวัตถุ ธีม และ layout ได้ เช่น พิซซ่า ดอกไม้ วงล้อ ระบบสุริยะ ต้นไม้ หรือวัตถุอื่นที่เหมาะกับบทเรียน

Gem จะวางโครงสร้างเนื้อหาก่อนสร้าง prompt เพื่อช่วยลดความผิดพลาดของข้อความ จำนวนช่อง และเนื้อหาวิชาการ

## เหมาะกับใคร

- ครูประถมและมัธยมต้น
- ผู้สร้างสื่อการสอน
- ผู้ปกครองที่ทำแบบฝึกเสริม
- ผู้พัฒนา printable worksheet

## เหมาะกับกิจกรรมแบบใด

เหมาะกับกิจกรรมที่มีคำตอบสั้นหรือรายการจำกัด เช่น:
- ยกตัวอย่างคำ
- เติมคำ
- ระบุส่วนประกอบ
- จำแนกหมวดหมู่
- คำศัพท์
- แม่สูตรคูณ / number facts
- ทบทวนหัวข้อ

ไม่เหมาะกับเรียงความหรือคำตอบปลายเปิดยาวโดยตรง หากหัวข้อเป็นปลายเปิด Gem ควรแปลงเป็นกิจกรรมย่อยที่มีคำตอบสั้นก่อน หรือเลือก worksheet format อื่นถ้าการแปลงทำให้เป้าหมายการเรียนรู้เปลี่ยนไป

## ค่าเริ่มต้น

หากไม่ระบุ:

```text
PAGE_SIZE = A4
ORIENTATION = PORTRAIT
MARGIN_MM = 10
SLOT_COUNT = 8
LANGUAGE = THAI
OBJECT_TYPE = AUTO
THEME = AUTO
LAYOUT_FAMILY = AUTO
MAIN_ART_COLOR_MODE = MONOCHROME
COLORING_FRIENDLY = YES
ANSWER_KEY = NO
```

ดังนั้นคำสั่งสั้น ๆ ก็เพียงพอ เช่น:

```text
สร้างใบงาน ป.1 ภาษาไทย เรื่องสระอา แบบวงล้อ 8 ช่อง
```

## วิธีสั่งแบบละเอียด

```text
สร้างใบงาน Themed Hub
ระดับชั้น: ป.3
วิชา: ภาษาไทย
หัวข้อ: มาตราตัวสะกด
เป้าหมาย: ให้นักเรียนยกตัวอย่างคำ
กิจกรรม: เขียนตัวอย่างคำ
จำนวนช่อง: 8 ช่อง
วัตถุ: พิซซ่า
ธีม: อาหารน่ารัก
ขนาดกระดาษ: A4
แนวกระดาษ: แนวตั้ง
รูปแบบ: ขาว-ดำ เส้นเรียบง่าย
ไม่ต้องมีเฉลย
```

## สิ่งที่ Gem ทำภายใน

Gem จะดำเนินการตามลำดับ:

```text
คำสั่งครู
→ วิเคราะห์วิชา/หัวข้อ/ระดับชั้น
→ กำหนดเป้าหมายการเรียนรู้
→ เลือกกิจกรรมและชนิดคำตอบ
→ สร้าง Verified Content Blueprint
→ วางจำนวนและบทบาทของช่อง
→ เลือกวัตถุ/ธีม/layout
→ สร้าง prompt
→ ตรวจเนื้อหา ภาษาไทย layout และงานพิมพ์
```

จุดสำคัญคือ **ไม่ควรปล่อยให้ image model คิดข้อความวิชาการหรือจำนวนช่องสำคัญเอง**

## Parameters ที่ผู้ใช้ควรรู้

- `GRADE_LEVEL` — ระดับชั้น
- `SUBJECT` — วิชา
- `TOPIC` — หัวข้อ
- `LEARNING_OBJECTIVE` — เป้าหมายการเรียนรู้ ถ้าต้องการกำหนดเอง
- `ACTIVITY_TYPE` — เด็กต้องทำอะไร
- `RESPONSE_TYPE` — คำ / ข้อความสั้น / ตัวเลข / expression / category ฯลฯ
- `SLOT_COUNT` — จำนวนช่อง
- `OBJECT_TYPE` — เช่น PIZZA, FLOWER, TREE, SOLAR_SYSTEM หรือ AUTO
- `THEME` — ธีมภาพ
- `LAYOUT_FAMILY` — RADIAL, RING, PETAL, SLICE, ORBIT, BRANCH ฯลฯ
- `PAGE_SIZE` — ขนาดกระดาษ
- `ORIENTATION` — แนวตั้ง/แนวนอน
- `ANSWER_KEY` — ต้องการเฉลยหรือไม่

ผู้ใช้ทั่วไปไม่จำเป็นต้องระบุทั้งหมด ให้ Gem เลือกค่า AUTO ที่เหมาะสม

## จำนวนช่อง

ช่วงที่เหมาะต่อหน้าโดยทั่วไปคือ 4–16 ช่อง

- 4–6 ช่อง: เหมาะกับคำตอบยาวขึ้น
- 7–10 ช่อง: สมดุลที่สุดบน A4
- 11–16 ช่อง: Gem จะลดของตกแต่งและจัด layout ให้เป็นระเบียบมากขึ้น
- มากกว่า 16 ช่อง: Gem ควรแบ่งหลายหน้าอัตโนมัติแทนการบีบช่อง

หลักคือ:

```text
พื้นที่เขียน > ของตกแต่ง
แบ่งหน้า > บีบจนอ่านหรือเขียนไม่ได้
```

## ตัวอย่างหลายวิชา

### ภาษาไทย
```text
ป.1 ภาษาไทย สระอา 8 ช่อง ธีมพิซซ่าน่ารัก A4 แนวตั้ง
```

### คณิตศาสตร์
```text
ป.2 คณิต แม่ 4 จำนวน 12 ช่อง ใช้วงล้อ ขาว-ดำ
```

### ภาษาอังกฤษ
```text
ป.3 English Animals vocabulary 10 ช่อง ธีมสวนสัตว์
```

### วิทยาศาสตร์
```text
ป.4 วิทยาศาสตร์ ส่วนประกอบของพืช 6 ช่อง ใช้ดอกไม้เป็นวัตถุหลัก
```

### ระบบสุริยะ
```text
ป.4 วิทยาศาสตร์ ระบบสุริยะ 8 ช่อง layout แบบวงโคจร A4 แนวนอน
```

## การปรับงานด้วยคำสั่งต่อเนื่อง

สามารถสั่งแก้เฉพาะส่วนได้ เช่น:

```text
เปลี่ยนจากพิซซ่าเป็นดอกไม้
```

```text
เพิ่มเป็น 10 ช่อง
```

```text
ขอช่องใหญ่ขึ้น ลดของตกแต่ง
```

```text
เปลี่ยนเป็น A4 แนวนอน แต่เนื้อหาเดิม
```

Gem ต้องเก็บค่าที่ผู้ใช้ไม่ได้เปลี่ยนไว้

## หลักการเลือกวัตถุและธีม

วัตถุ/ธีมเป็น **visual container** มีหน้าที่ช่วยการมองเห็นและแรงจูงใจเท่านั้น ต้องไม่เปลี่ยนข้อเท็จจริงทางวิชาการ

ตัวอย่าง:
- ส่วนประกอบของพืช → FLOWER / TREE
- ระบบสุริยะ → SOLAR_SYSTEM / ORBIT
- แม่สูตรคูณ → WHEEL / SUN / RADIAL
- สระ/คำศัพท์ → PIZZA / FLOWER / BALLOON_CLUSTER

ถ้าวัตถุที่ผู้ใช้สั่งไม่เข้ากับหัวข้อ แต่ยังไม่ทำให้ความหมายผิด Gem สามารถใช้เป็นเพียงภาชนะเชิงภาพได้

## กรณีจำนวนช่องเยอะ

ตัวอย่าง:

```text
ป.3 ภาษาไทย คำควบกล้ำ 24 ช่อง A4 แนวตั้ง
```

Gem ควรแบ่งหลายหน้า ไม่ควรยัด 24 ช่องให้เล็กจนเขียนไม่ได้

## กรณีคำตอบยาว

หากผู้ใช้ต้องการคำตอบยาวมากในแต่ละช่อง Gem ควร:
- ย่อเป็น key phrase ถ้ายังรักษา learning objective ได้
- เปลี่ยน layout
- แบ่งหลายหน้า
- หรือแจ้งว่า worksheet format นี้ไม่เหมาะ

## การตรวจผลลัพธ์ก่อนใช้งานจริง

ตรวจอย่างน้อย:
1. วิชา หัวข้อ และระดับชั้นตรงคำสั่ง
2. เป้าหมายการเรียนรู้เหมาะสม
3. คำ/คำตอบหรือคำชี้แจงถูกต้อง
4. จำนวนช่องตรงที่ขอ
5. ช่องใหญ่พอให้เด็กเขียน
6. ข้อความไม่ชนภาพหรือเส้น
7. ภาษาไทยสะกดถูกและเหมาะกับวัย
8. วัตถุ/ธีมไม่ทำให้เนื้อหาสับสน
9. ขนาดกระดาษและ orientation ถูกต้อง
10. พิมพ์ขาว-ดำแล้วยังอ่านง่าย

## ข้อจำกัด

- image model อาจสร้างข้อความไทยหรือจำนวนช่องผิดได้ จึงควรใช้ deterministic text/layout เมื่อระบบรองรับ
- ไม่ควรให้ image model คิดคำตอบทางวิชาการสำคัญเอง
- กิจกรรมที่ต้องเขียนยาวควรใช้ worksheet format อื่น
- การสร้าง prompt ไม่เท่ากับการสร้าง PDF/PNG จริง
