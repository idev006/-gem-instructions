# Themed Hub Worksheet — คู่มือการใช้งาน

Version: 1.0.0
Status: User Guide

## Gem นี้ใช้ทำอะไร

Gem นี้ช่วยสร้าง prompt สำหรับออกแบบใบงานแบบมีหัวข้อหลักอยู่ตรงกลาง และมีช่องกิจกรรม/คำตอบกระจายรอบ ๆ โดยสามารถเปลี่ยนวัตถุ ธีม และรูปแบบ layout ได้ เช่น พิซซ่า ดอกไม้ วงล้อ ระบบสุริยะ ต้นไม้ หรือวัตถุอื่นที่เหมาะกับบทเรียน

## เหมาะกับใคร

- ครูประถมและมัธยมต้น
- ผู้สร้างสื่อการสอน
- ผู้ปกครองที่ทำแบบฝึกเสริม
- ผู้พัฒนาสื่อ printable worksheet

## เหมาะกับกิจกรรมแบบใด

เหมาะกับกิจกรรมที่มีคำตอบสั้นหรือรายการจำกัด เช่น:
- ยกตัวอย่างคำ
- เติมคำ
- ระบุส่วนประกอบ
- จำแนกหมวดหมู่
- คำศัพท์
- แม่สูตรคูณ/ผลลัพธ์สั้น
- ทบทวนหัวข้อ

ไม่เหมาะกับเรียงความหรือคำตอบปลายเปิดยาวโดยตรง หากหัวข้อเป็นปลายเปิด Gem ควรแปลงเป็นกิจกรรมย่อยที่มีคำตอบสั้นก่อน

## ค่าเริ่มต้น

หากไม่ระบุ:

```text
PAGE_SIZE = A4
ORIENTATION = PORTRAIT
SLOT_COUNT = 8
LANGUAGE = THAI
OBJECT_TYPE = AUTO
THEME = AUTO
LAYOUT_FAMILY = AUTO
MAIN_ART_COLOR_MODE = MONOCHROME
COLORING_FRIENDLY = YES
ANSWER_KEY = NO
```

ดังนั้นคำสั่งสั้น ๆ ก็เพียงพอ เช่น:

```text
สร้างใบงาน ป.1 ภาษาไทย เรื่องสระอา แบบวงล้อ 8 ช่อง
```

## วิธีสั่งแบบละเอียด

```text
สร้างใบงาน Themed Hub
ระดับชั้น: ป.3
วิชา: ภาษาไทย
หัวข้อ: มาตราตัวสะกด
กิจกรรม: ให้เขียนตัวอย่างคำ
จำนวนช่อง: 8 ช่อง
วัตถุ: พิซซ่า
ธีม: อาหารน่ารัก
ขนาดกระดาษ: A4
แนวกระดาษ: แนวตั้ง
รูปแบบ: ขาว-ดำ เส้นเรียบง่าย
ไม่ต้องมีเฉลย
```

## Parameters ที่ผู้ใช้ควรรู้

- `GRADE_LEVEL` — ระดับชั้น
- `SUBJECT` — วิชา
- `TOPIC` — หัวข้อ
- `ACTIVITY_TYPE` — เด็กต้องทำอะไร
- `SLOT_COUNT` — จำนวนช่อง 4–16
- `OBJECT_TYPE` — วัตถุหลัก เช่น PIZZA, FLOWER, TREE, SOLAR_SYSTEM หรือ AUTO
- `THEME` — ธีมภาพ
- `LAYOUT_FAMILY` — RADIAL, RING, PETAL, SLICE, ORBIT, BRANCH ฯลฯ
- `PAGE_SIZE` — A4 หรือขนาดที่รองรับ
- `ORIENTATION` — แนวตั้ง/แนวนอน
- `ANSWER_KEY` — ต้องการเฉลยหรือไม่

ผู้ใช้ทั่วไปไม่จำเป็นต้องระบุทั้งหมด ให้ Gem เลือกค่า AUTO ที่เหมาะสม

## ตัวอย่างหลายวิชา

### ภาษาไทย

```text
ป.1 ภาษาไทย สระอา 8 ช่อง ธีมพิซซ่าน่ารัก A4 แนวตั้ง
```

### คณิตศาสตร์

```text
ป.2 คณิต แม่ 4 จำนวน 12 ช่อง ใช้วงล้อ ขาว-ดำ
```

### ภาษาอังกฤษ

```text
ป.3 English Animals vocabulary 10 ช่อง ธีมสวนสัตว์
```

### วิทยาศาสตร์

```text
ป.4 วิทยาศาสตร์ ส่วนประกอบของพืช 6 ช่อง ใช้ดอกไม้เป็นวัตถุหลัก
```

### ระบบสุริยะ

```text
ป.4 วิทยาศาสตร์ ระบบสุริยะ 8 ช่อง layout แบบวงโคจร A4 แนวนอน
```

## การปรับงานด้วยคำสั่งต่อเนื่อง

สามารถสั่งแก้เฉพาะส่วนได้ เช่น:

```text
เปลี่ยนจากพิซซ่าเป็นดอกไม้
```

```text
เพิ่มเป็น 10 ช่อง
```

```text
ขอช่องใหญ่ขึ้น ลดของตกแต่ง
```

```text
เปลี่ยนเป็น A4 แนวนอน แต่เนื้อหาเดิม
```

```text
ทำให้เหมาะกับเด็ก ป.1 มากขึ้น
```

ค่าที่ผู้ใช้ไม่ได้เปลี่ยนควรถูกเก็บไว้

## หลักการเลือกวัตถุและธีม

วัตถุ/ธีมมีหน้าที่ช่วยการมองเห็นและแรงจูงใจเท่านั้น ต้องไม่ทำให้เนื้อหาวิชาการผิดหรือสับสน

ตัวอย่างการจับคู่ที่เหมาะ:
- ส่วนประกอบของพืช → FLOWER / TREE
- ระบบสุริยะ → SOLAR_SYSTEM / ORBIT
- แม่สูตรคูณ → WHEEL / SUN / RADIAL
- สระ/คำศัพท์ → PIZZA / FLOWER / BALLOON_CLUSTER ได้ตามธีม

ถ้าวัตถุที่ผู้ใช้สั่งไม่เข้ากับหัวข้อ ให้ยังคงทำได้ถ้าไม่ทำให้ความหมายผิด แต่ต้องรักษาความอ่านง่ายและประโยชน์ของกิจกรรมเหนือความสวยงาม

## การตรวจผลลัพธ์ก่อนใช้งานจริง

ตรวจอย่างน้อย:
1. วิชาและหัวข้อตรงคำสั่ง
2. คำ/คำตอบหรือคำชี้แจงถูกต้อง
3. จำนวนช่องตรงที่ขอ
4. ช่องใหญ่พอให้เด็กเขียน
5. ข้อความไม่ชนภาพหรือเส้น
6. ภาษาไทยสะกดถูกและเหมาะกับวัย
7. วัตถุ/ธีมไม่ทำให้เนื้อหาสับสน
8. ขนาดกระดาษและ orientation ถูกต้อง
9. พิมพ์ขาว-ดำแล้วยังอ่านง่าย

## ข้อจำกัด

- image model อาจสร้างข้อความไทยหรือจำนวนช่องผิดได้ จึงควรใช้ deterministic text/layout เมื่อระบบรองรับ
- ไม่ควรให้ image model คิดคำตอบทางวิชาการที่สำคัญเอง
- กิจกรรมที่ต้องเขียนยาวควรใช้ worksheet format อื่น
- ถ้าจำนวนช่องมากขึ้น ต้องลดของตกแต่งก่อนลดขนาดพื้นที่เขียน
