# Themed Hub Worksheet — Usage Examples

## Defaults
- A4
- Portrait
- 8 slots
- Thai-first
- monochrome main artwork
- simple coloring-friendly line art
- object/theme/layout = AUTO when omitted

## Happy path — ภาษาไทย

```text
สร้างใบงาน ป.1 ภาษาไทย เรื่องสระอา 8 ช่อง ธีมพิซซ่า A4 แนวตั้ง
```

## Minimal prompt

```text
ป.2 คณิต แม่ 4 แบบวงล้อ
```

ระบบควร resolve เป็น A4 แนวตั้ง, 8 ช่อง, ขาว-ดำ และเลือก activity ที่เหมาะสมอัตโนมัติ

## Detailed prompt

```text
สร้างใบงาน Themed Hub
ระดับชั้น: ป.3
วิชา: ภาษาไทย
หัวข้อ: มาตราตัวสะกด
เป้าหมาย: ให้นักเรียนยกตัวอย่างคำที่อยู่ในมาตราที่กำหนด
กิจกรรม: เขียนตัวอย่างคำ
จำนวนช่อง: 10 ช่อง
วัตถุ: ดอกไม้
ธีม: สวน
ขนาดกระดาษ: A4
แนวกระดาษ: แนวตั้ง
รูปแบบ: ขาว-ดำ เส้นเรียบง่าย
แสดงชื่อ ชั้น เลขที่ วันที่
ไม่ต้องมีเฉลย
```

## หลายวิชา

### ภาษาไทย
```text
สร้างใบงาน ป.4 ภาษาไทย เรื่องคำควบกล้ำ 8 ช่อง ใช้วงล้อรถ ธีมรถแข่ง
```

### คณิตศาสตร์
```text
สร้างใบงาน ป.3 คณิตศาสตร์ number bonds ของ 20 จำนวน 8 ช่อง ใช้ดวงอาทิตย์
```

### ภาษาอังกฤษ
```text
สร้างใบงาน ป.3 English Vocabulary Animals 10 ช่อง ธีมสวนสัตว์
```

### วิทยาศาสตร์
```text
สร้างใบงาน ป.4 วิทยาศาสตร์ เรื่องส่วนประกอบของพืช 6 ช่อง ใช้ดอกไม้ A4 แนวตั้ง
```

```text
สร้างใบงาน ป.5 วิทยาศาสตร์ ระบบสุริยะ 8 ช่อง ใช้ layout แบบ orbit ธีมอวกาศ
```

### สังคมศึกษา
```text
สร้างใบงาน ป.5 สังคมศึกษา เรื่องทวีป 7 ช่อง ใช้แผนที่โลก ขาว-ดำ
```

## Revision prompts

```text
เปลี่ยนจากพิซซ่าเป็นดอกทานตะวัน แต่คงหัวข้อ จำนวนช่อง และกระดาษเดิม
```

```text
เพิ่มจาก 8 ช่องเป็น 10 ช่อง และลดของตกแต่งเพื่อให้มีพื้นที่เขียนมากขึ้น
```

```text
เปลี่ยนเป็น A4 แนวนอน แต่คงเนื้อหาเดิมทั้งหมด
```

## Edge case — ขอช่องมากเกินช่วงแนะนำ

```text
ป.3 ภาษาไทย คำควบกล้ำ 24 ช่อง ธีมรถแข่ง A4 แนวตั้ง
```

Expected behavior:
- ไม่บีบ 24 ช่องลงหน้าเดียว
- ใช้ auto-pagination
- คงหัวข้อและธีม
- กระจายช่องหลายหน้าโดยรักษาพื้นที่เขียน

## Edge case — หัวข้อปลายเปิด

```text
ป.5 สังคมศึกษา เรื่องการเป็นพลเมืองดี ให้เด็กอธิบายความคิดเห็น 8 ช่อง
```

Expected behavior:
- ไม่สร้างช่องสำหรับเรียงความยาวโดยตรง
- แปลงเป็นกิจกรรมย่อยที่ตอบสั้นได้ เช่น “ยกตัวอย่างพฤติกรรมของพลเมืองดี 8 ข้อ” เมื่อยังรักษาเจตนาการเรียนรู้ได้

## Edge case — object ไม่เหมาะกับหัวข้อ

```text
ป.4 วิทยาศาสตร์ ระบบสุริยะ 8 ช่อง ใช้พิซซ่า
```

Expected behavior:
- ถ้ายังใช้งานได้โดยไม่ทำให้ความหมายผิด สามารถใช้ pizza เป็น visual container เท่านั้น
- ห้ามเปลี่ยนชื่อดาวหรือข้อมูลวิทยาศาสตร์ให้เข้ากับธีมอาหาร
- ถ้ารูปทรงทำให้กิจกรรมสับสน ให้เสนอ/resolve layout ที่เป็นกลางกว่าโดยรักษาคำขอให้มากที่สุด

## Edge case — ข้อความยาวเกินช่อง

```text
ป.4 วิทยาศาสตร์ ให้เขียนคำอธิบายยาวเกี่ยวกับหน้าที่ของส่วนประกอบพืช 8 ช่อง
```

Expected behavior:
- ย่อเป็นคำตอบสั้นหรือ key phrase ถ้าไม่เสีย learning objective
- หรือเลือก layout/แบ่งหน้าเพื่อให้เขียนได้จริง
- ห้ามลดตัวอักษรจนอ่านยาก

## Edge case — ไม่ระบุ object/theme

```text
ป.1 ภาษาไทย สระอา 8 ช่อง
```

Expected behavior:
- ใช้ OBJECT_TYPE=AUTO และ THEME=AUTO
- ไม่ถามเพิ่มโดยไม่จำเป็น

## Full monochrome print request

```text
สร้างใบงาน ป.2 คณิตศาสตร์ แม่ 5 แบบวงล้อ 8 ช่อง A4 แนวตั้ง ขาว-ดำล้วน พิมพ์ถ่ายเอกสารง่าย
```
