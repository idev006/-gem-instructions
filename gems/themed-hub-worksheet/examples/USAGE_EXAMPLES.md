# Themed Hub Worksheet — Usage Examples

## Defaults
- A4
- Portrait
- 8 slots
- Thai-first
- monochrome main artwork
- simple coloring-friendly line art

## ภาษาไทย

```text
สร้างใบงาน ป.1 ภาษาไทย เรื่องสระอา 8 ช่อง ธีมพิซซ่า A4 แนวตั้ง
```

```text
สร้างใบงาน ป.3 ภาษาไทย เรื่องมาตราตัวสะกด 10 ช่อง ใช้ดอกไม้ ธีมสวน ขาว-ดำ
```

```text
สร้างใบงาน ป.4 ภาษาไทย เรื่องคำควบกล้ำ 8 ช่อง ใช้วงล้อรถ ธีมรถแข่ง
```

## คณิตศาสตร์

```text
สร้างใบงาน ป.2 คณิตศาสตร์ แม่ 4 แบบวงล้อ 12 ช่อง A4 แนวตั้ง
```

```text
สร้างใบงาน ป.3 คณิตศาสตร์ number bonds ของ 20 จำนวน 8 ช่อง ใช้ดวงอาทิตย์
```

## ภาษาอังกฤษ

```text
สร้างใบงาน ป.3 English Vocabulary Animals 10 ช่อง ธีมสวนสัตว์
```

```text
สร้างใบงาน ป.2 English Word Family -at จำนวน 8 ช่อง ใช้ดอกไม้
```

## วิทยาศาสตร์

```text
สร้างใบงาน ป.4 วิทยาศาสตร์ เรื่องส่วนประกอบของพืช 6 ช่อง ใช้ดอกไม้ A4 แนวตั้ง
```

```text
สร้างใบงาน ป.5 วิทยาศาสตร์ ระบบสุริยะ 8 ช่อง ใช้ layout แบบ orbit ธีมอวกาศ
```

## สังคมศึกษา

```text
สร้างใบงาน ป.5 สังคมศึกษา เรื่องทวีป 7 ช่อง ใช้แผนที่โลก ขาว-ดำ
```

## Revision examples

```text
เปลี่ยนจากพิซซ่าเป็นดอกทานตะวัน แต่คงหัวข้อและจำนวนช่องเดิม
```

```text
เพิ่มจาก 8 ช่องเป็น 10 ช่อง และลดของตกแต่งเพื่อให้มีพื้นที่เขียนมากขึ้น
```
