# Prompt Generator Acceptance Tests

Version: 1.4.0
Applies to Gem baseline: 2.6.x
Status: Critical regression suite

A critical failure blocks production prompt release.

## A. Product/output contract

### PG-01 — Primary deliverable
Normal worksheet request produces non-empty `FINAL_IMAGE_GENERATION_PROMPT`.

### PG-02 — Standalone copy-ready
Copy only the final prompt to a new context. It contains learner, topic, page, count, layout, student text/givens, blanks, visual states, constraints and hard negatives without relying on earlier sections.

### PG-03 — No placeholders
Forbidden: `[ภาพ...]`, `[รูป...]`, `<draw here>`, `TBD`, `same as above`, `use blueprint above`, omitted visual states via `etc.`.

### PG-04 — Exact count
For N questions, Student Blueprint and final prompt each represent exactly N student items; visual tasks have exactly N item render states.

### PG-05 — One resolved render path
Final prompt contains exactly one of `DOCUMENT_FIRST|HYBRID|DETERMINISTIC_VECTOR|IMAGE_ONLY`. `AUTO` and `A or B` alternatives are not release values.

### PG-06 — Render objective
Final prompt requires `RENDER_OBJECTIVE=STUDENT_WORKSHEET` and prohibits QA dashboard/meta prompt as worksheet output.

## B. Worker architecture

### PG-07 — Base workers
W01..W09 all present, unique, `BASELINE_COMPATIBILITY=2.6.x`, `WORKER_SCHEMA_VERSION=1`.

### PG-08 — Route ownership
Academic rule is generated by its owning worker. W07 audits geometry, W08 layout/render/Thai, W09 release. Cross-worker formula override = FAIL.

### PG-09 — Visual auditor route
Clock/dial/ruler/protractor/thermometer/graduated capacity and exact learner-read graph geometry include W07.

### PG-10 — Universal workers
Every production request includes W08 + W09.

### PG-11 — Mixed-domain route
Mixed worksheet selects every owning academic worker without one domain silently overwriting another's units/formulas.

## C. Visibility/answer integrity

### PG-12 — Three scopes
System distinguishes INTERNAL, TEACHER_VISIBLE_PROMPT_METADATA, STUDENT_VISIBLE_WORKSHEET.

### PG-13 — Student Blueprint no renderer target
When key is off, Student Blueprint contains no target time/weight/length/angle/level, hand/needle/ray angle, tick index, liquid level, solved answer or renderer relation string.

### PG-14 — Renderer metadata retained
High-risk visual metadata required for correct drawing may appear in final prompt marked `RENDER_ONLY_NOT_FOR_WORKSHEET`; sanitizer must not remove it merely because it contains the hidden semantic target.

### PG-15 — Student-visible answer leak
Blank answers remain blank; no solved list/key/QA prose prints a learner answer when key is off.

### PG-16 — Canonical-label preservation
Leak guard must not remove legitimate clock 1–12, dial 0–5, ruler/protractor/thermometer/capacity labels or graph labels.

### PG-17 — Separate answer key
When key is on, default is unsolved student worksheet + separate answer key unless inline solved is explicitly requested.

## D. High-risk visual serialization

### PG-18 — Redundant visual state
Every high-risk visual item has `SEMANTIC TARGET + EXACT INDEX/ANGLE/LEVEL + RELATIONAL WORDING + ITEM-SPECIFIC HARD NEGATIVE`.

### PG-19 — Clock 10:30
10:30 final prompt states minute 180°/at 6, hour 315°, midpoint 10–11, and hard negative not directly on 10.

### PG-20 — Nonzero-minute clock
For every `m!=00`, hour angle includes `0.5*m` displacement; semantic-only `show h:m` is insufficient.

### PG-21 — Canonical 0–5 kg dial
300° active sweep, visible 60° inactive gap, 50 intervals/51 positions, no gap ticks, explicit no-360° substitution, labels 0–5 preserved.

### PG-22 — Linear scale topology
Ruler/thermometer/capacity specify range, minor interval, exact interval count and endpoint-inclusive position count.

### PG-23 — Protractor serialization
Learner-read protractor specifies vertex/origin, selected 0° baseline, active scale direction, exact target graduation and item-specific hard negative against reading the wrong scale.

## E. Measurement calculation expansion

### PG-24 — Time units
Require exact `60 s=1 min`, `60 min=1 h`, `24 h=1 day`; second precision only when requested/warranted.

### PG-25 — Seconds-hand guard
Time-unit conversion alone must not automatically add a seconds hand to an analog clock.

### PG-26 — Length conversions
Require `10 mm=1 cm`, `100 cm=1 m`, `1000 m=1 km`. Mixed-unit arithmetic normalizes before calculation.

### PG-27 — Ruler nonzero start
If start is nonzero, verified length=`end-start`; physical ruler edge is not silently treated as zero.

### PG-28 — Ruler 1 mm topology
0–1 cm @1 mm has 10 intervals and 11 endpoint-inclusive positions.

### PG-29 — Distance total
Multi-segment total sums each segment exactly once after unit normalization.

### PG-30 — Round trip
`2×one_way` only when same route is explicit/clear. Asymmetric outbound/return sums separately.

### PG-31 — Route comparison
Each route independently totaled before comparison/difference.

### PG-32 — Distance is not speed
A distance task must not silently introduce speed/rate formulas.

### PG-33 — Protractor topology
0–180° @1° has 180 intervals / 181 endpoint-inclusive positions; selected inner/outer scale direction is unambiguous.

### PG-34 — Perimeter
Perimeter counts each boundary side exactly once and normalizes units before summation.

### PG-35 — Area formula
Figure uses its owned formula; triangle/parallelogram/trapezoid height is perpendicular height.

### PG-36 — Squared-unit conversion
`1 m²=10,000 cm²`, `1 km²=1,000,000 m²`; reject linear conversion factor for area.

### PG-37 — Circle π policy
Circle worksheet declares one `PI_POLICY` and applies it consistently.

### PG-38 — Weight conversion
`1000 g=1 kg`; when Thai ขีด mode applies, `1 ขีด=100 g=0.1 kg`.

### PG-39 — Capacity conversion
`1000 mL=1 L`; mixed-unit arithmetic normalizes before calculation.

### PG-40 — Thermometer representability
Discrete target must equal `MIN+k*MINOR_INTERVAL`; endpoint exactly on graduation and prohibits unintended between-tick placement.

### PG-41 — Meniscus
Bottom mode = concave lowest point at target; top mode = appropriate curved highest designated point at target. Target number must not become annotation.

### PG-42 — Rectangular-prism volume
All dimensions use compatible units before `V=l×w×h`; cubic unit is correct.

### PG-43 — Composite rectangular-prism volume
Components are non-overlapping, each counted once, no double-counted overlap.

### PG-44 — Cubic-unit conversion
Require `1000 cm³=1 dm³`, `1000 dm³=1 m³`, `1 m³=1,000,000 cm³`; reject linear conversion factors.

### PG-45 — Capacity-volume relation scope
`1 cm³=1 mL`, `1 dm³=1 L`, `1 m³=1000 L` only when explicitly appropriate; do not inject into unrelated early-grade capacity tasks.

## F. Grade/layout/Thai

### PG-46 — Grade progression
AUTO difficulty follows conservative P1–P6 progression; higher grade alone does not force advanced complexity beyond objective.

### PG-47 — One-page preferred
Normal request tries one page first without sacrificing correctness/readability/minimum geometry.

### PG-48 — One-page lock
Explicit one-page request cannot silently paginate, crop, reduce count or merge graduations; unsafe fit blocks release.

### PG-49 — Thai text
Canonical Thai spelling/units/header/response blanks are locked; downstream prompt prohibits paraphrasing/invented required labels.

## G. Prompt vs artifact QA

### PG-50 — Prompt phase only
Before downstream image exists, prompt checks may PASS but actual geometry/glyph visual checks may not be reported PASS.

### PG-51 — Artifact status
Before image inspection output includes `ARTIFACT_QA=NOT_YET_TESTED` and `CLASSROOM_RELEASE=WAITING_FOR_ARTIFACT_QA`.

### PG-52 — One wrong instrument blocks artifact release
After image exists, one wrong learner-read needle/hand/tick/ray/endpoint/level blocks classroom release.

## H. Revision/hotfix

### PG-53 — Canonical-state revision
Theme/orientation/count/difficulty/unit/range changes modify canonical state first and rerun affected workers; do not patch final prose only.

### PG-54 — Hotfix compatibility
W10, if present, declares baseline 2.6.x, target worker, narrow scope, replaced/new rule and regression test. Broad architecture override = FAIL.

## Release principle

`VERIFIED + WORKER-OWNED + STUDENT-SAFE + UNIT-CORRECT + SELF-CONTAINED + PLACEHOLDER-FREE + COPY-READY + PHASE-CORRECT`

A prompt that is academically plausible but leaves unit conversion, route relation, scale direction, squared/cubic conversion, or high-risk geometry to renderer inference is incomplete.
