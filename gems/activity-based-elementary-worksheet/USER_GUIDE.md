# คู่มือใช้งาน Activity-Based Elementary Worksheet Generator

Version: 1.0.0

Gem นี้ใช้สร้าง **ชุด Prompt สำหรับใบงานประถมศึกษาแบบกิจกรรม (Activity-Based Worksheet)** โดยเน้นความถูกต้องของเนื้อหาก่อนความสวยงาม และเหมาะอย่างยิ่งกับใบงานที่มีข้อมูลเป็นแถว เช่น กิจกรรม + เวลาเริ่มต้น + เวลาสิ้นสุด + ช่องคำตอบ

## เหมาะกับใคร

- ครูประถมศึกษา
- ผู้สร้างสื่อการเรียนการสอน
- นักออกแบบใบงาน
- ผู้จัดทำสื่อ Printable PDF
- ผู้ใช้ AI สร้างภาพที่ต้องการ Prompt ซึ่งมีข้อมูลโจทย์ผ่านการตรวจสอบแล้ว

## ใช้ทำอะไรได้

รุ่นแรกเน้น `TIME_ENGINE` เช่น:

- การหาระยะเวลาจากเวลาเริ่มต้นและเวลาสิ้นสุด
- ชั่วโมงเต็ม
- ชั่วโมงและนาที
- ตารางกิจกรรมประจำวัน
- รูปแบบโจทย์ที่มีไอคอนกิจกรรมและช่องตอบ

สถาปัตยกรรมรองรับการขยายไปยังเงิน การวัด ปฏิทิน ตาราง และโจทย์สถานการณ์ในอนาคต

## วิธีสั่งงานแบบสั้น

ตัวอย่าง:

> สร้างใบงาน ป.3 คณิตศาสตร์ เรื่องการหาระยะเวลา 10 ข้อ ธีมกิจกรรมประจำวัน A4 แนวตั้ง ขาวดำ ไม่ต้องมีเฉลย

Gem จะเติมค่า default ที่ปลอดภัยให้เอง เช่น:

- ภาษาไทย
- A4 แนวตั้ง
- ขาวดำ
- มีช่อง ชื่อ / ชั้น / เลขที่
- มีคำชี้แจง
- มีหมายเลขข้อ
- ไอคอนกิจกรรมแบบเส้นขาวดำ
- ไม่สร้างเฉลยเมื่อไม่ได้ร้องขอ

## วิธีสั่งงานแบบละเอียด

ตัวอย่าง:

> สร้างใบงาน ป.3 คณิตศาสตร์ เรื่องการบอกระยะเวลาเป็นชั่วโมงและนาที จำนวน 10 ข้อ ระดับปานกลาง ให้ทุกข้อเป็นกิจกรรมในชีวิตประจำวัน ใช้เวลาแบบ 24 ชั่วโมง อนุญาตคำตอบทั้งชั่วโมงและนาที นาทีเป็นช่วงละ 5 นาที ไม่ข้ามเที่ยงคืน A4 แนวตั้ง ขาวดำ มีชื่อ ชั้น เลขที่ มีหมายเลขข้อ ไม่ต้องมีเฉลย ใช้ภาพประกอบเส้นแบบน่ารักแต่ไม่กินพื้นที่โจทย์

## Parameters สำคัญ

### เนื้อหา

- `GRADE_LEVEL` — ระดับชั้น
- `SUBJECT` — วิชา
- `TOPIC` — หัวข้อ
- `QUESTION_COUNT` — จำนวนข้อ
- `DIFFICULTY` — EASY / MEDIUM / HARD / AUTO
- `QUESTION_TYPE` — ชนิดโจทย์
- `SHOW_ANSWER_KEY` — YES / NO

### เรื่องเวลา

- `TIME_FORMAT` — 24_HOUR / 12_HOUR
- `START_TIME_RANGE` — ช่วงเวลาเริ่มต้น
- `MIN_DURATION` / `MAX_DURATION`
- `ALLOW_FULL_HOURS_ONLY`
- `ALLOW_MINUTES`
- `MINUTE_INTERVAL`
- `TIME_CROSS_NOON_ALLOWED`
- `TIME_CROSS_MIDNIGHT_ALLOWED`
- `ANSWER_UNIT_MODE`

### หน้าและการออกแบบ

- `PAGE_SIZE`
- `ORIENTATION`
- `COLOR_MODE`
- `DENSITY_MODE`
- `AUTO_PAGINATION`
- `VISUAL_THEME`
- `ART_STYLE`
- `DECORATION_DENSITY`

### ส่วนหัว

- `SHOW_STUDENT_HEADER`
- `HEADER_FIELDS`
- `WORKSHEET_TITLE`
- `SHOW_INSTRUCTION`
- `INSTRUCTION_TEXT`

## Default สำคัญ

หากผู้ใช้ไม่ได้ระบุค่า:

- `PAGE_SIZE = A4`
- `ORIENTATION = PORTRAIT`
- `COLOR_MODE = BLACK_AND_WHITE`
- `LANGUAGE = THAI`
- `SHOW_STUDENT_HEADER = YES`
- `HEADER_FIELDS = ชื่อ / ชั้น / เลขที่`
- `SHOW_QUESTION_NUMBER = YES`
- `SHOW_ANSWER_KEY = NO`
- `AUTO_PAGINATION = YES`
- `CONTEXT_MODE = EVERYDAY_ACTIVITY`

## รูปแบบผลลัพธ์

ตามค่า default Gem จะสร้าง 6 ส่วน:

1. `NORMALIZED_WORKSHEET_SPEC`
2. `VERIFIED_CONTENT_BLUEPRINT`
3. `LAYOUT_BLUEPRINT`
4. `RENDER_CONSTRAINTS`
5. `QA_REPORT`
6. `FINAL_IMAGE_GENERATION_PROMPT`

จุดสำคัญคือคำตอบที่ถูกต้องจะถูกเก็บใน Blueprint เพื่อ QA แต่หาก `SHOW_ANSWER_KEY = NO` คำตอบเหล่านั้นจะไม่ถูกพิมพ์ลงในช่องคำตอบของนักเรียน

## วิธีแก้งานด้วย Follow-up

สามารถสั่งแก้แบบธรรมชาติ เช่น:

> เปลี่ยนเป็นระดับยาก และให้มีคำตอบเป็นชั่วโมงกับนาที

> เปลี่ยนธีมภาพเป็นโลกอวกาศ แต่คงโจทย์เดิมทุกข้อ

> ลดเหลือ 8 ข้อ และขยายช่องคำตอบ

> เอาหมายเลขข้อออก

> เปลี่ยนเป็นแนวนอน แต่ห้ามเปลี่ยนเวลาและคำตอบเดิม

Gem ต้องอัปเดต `NORMALIZED_WORKSHEET_SPEC` และ rerun QA ที่ได้รับผลกระทบก่อนสร้าง Prompt ใหม่

## แนวทางตรวจผลก่อนนำไปใช้จริง

แม้ Gem จะทำ QA ภายใน ผู้ใช้ควรตรวจภาพที่ได้จาก image model อีกครั้ง โดยเฉพาะ:

- ตัวอักษรไทยสะกดถูกหรือไม่
- เวลาในภาพตรงกับ Prompt หรือไม่
- จำนวนข้อครบหรือไม่
- ไม่มีข้อซ้ำ
- ช่องคำตอบยังว่าง
- ไม่มีเฉลยหลุดเข้าใบงาน
- ไม่มีข้อความหรือรูปถูกตัดขอบ
- ขนาดตัวอักษรอ่านได้เมื่อตีพิมพ์ A4

เหตุผลคือ generative image model อาจทำข้อความหรือตัวเลขผิดได้แม้ Prompt ถูกต้อง

## ข้อจำกัด

Gem สามารถล็อกข้อมูลใน Prompt และลดความผิดพลาดได้ แต่ไม่สามารถรับประกันว่าโมเดลสร้างภาพทุกตัวจะพิมพ์ภาษาไทยและตัวเลขได้ถูกต้อง 100%

สำหรับงานที่ต้องการความถูกต้องระดับเอกสารพิมพ์จริง แนะนำ workflow แบบ deterministic overlay เช่น:

1. สร้างภาพ/illustration และโครงสร้างพื้นฐาน
2. วางข้อความไทยและตัวเลขด้วยระบบ layout หรือโปรแกรมกราฟิก
3. ตรวจ QA อีกครั้งก่อน export PDF

## กรณีที่ไม่เหมาะ

ไม่ควรใช้ Gem นี้เป็นตัวหลักสำหรับ:

- ข้อสอบข้อความยาวหลายหน้า
- แบบฝึกอ่านจับใจความขนาดใหญ่
- งานที่ต้องเลียนแบบเอกสารต้นฉบับแบบ pixel-perfect
- งานที่ต้องใช้ตัวละคร/โลโก้มีลิขสิทธิ์โดยไม่ได้รับอนุญาต
- งานที่มีสูตรหรือ domain ซึ่งยังไม่มี validation engine แต่ต้องการรับประกันทางคณิตศาสตร์

## หลักการสำคัญ

Gem ใช้แนวทาง:

`CONTENT FIRST → VERIFY → LAYOUT → PROMPT → IMAGE`

ไม่ใช่:

`IMAGE FIRST → ใส่โจทย์ทีหลัง`

ดังนั้นความถูกต้องทางการศึกษาและความสามารถในการใช้งานจริงของเด็กคือข้อกำหนดอันดับต้น
